# 三味線 学習用シミュレーター

勘所（つぼ）と文化譜を見ながら、ブラウザで三味線の練習ができる学習用Webアプリです。
タブレット・Chromebook・スマホ・パソコンで動きます。

## できること

- **自由に弾く**: 棹の勘所をタップすると、その場所を押さえて弾いた音が鳴ります。胴の部分は開放弦（0）。
  押したまま指をすべらせると「スリ」。パソコンではキーボードでも弾けます。
  「同じ音の場所」をオンにすると、弾いた音と同じ高さが出るほかの糸の勘所も表示します。
- **曲の練習**: 文化譜（3本線の楽譜）を見ながら、光る勘所を順番に弾いていきます。
  「お手本を聴く」で自動演奏（速さも選べます）。まちがえると、どこが違うかを教えてくれます
  （同じ音で3回まちがえると、正しい音を鳴らして教えてくれます）。
  - **テンポ練習**: メトロノームに合わせて弾き、ぴったり／おしい／ミスを判定して得点を表示。
  - **区間練習**: 「さくら さくら」などの区切りを、できるまで何度もくり返せます。
  - 収録曲（10曲）: 開放弦の練習 / 音階れんしゅう（本調子・二上り・三下り）/ かえるの合唱 / メリーさんのひつじ /
    チューリップ / きらきら星 / よろこびの歌 / さくらさくら
  - 曲ごとに「✓ 弾けた」「★ 完ぺき」を記録し、終わったら「次の曲へ」進める。
  - まちがえると「もう少し胴の方へ」「糸がちがいます」など、直し方を具体的に教える。
  - 「🖨 印刷」で文化譜を配布プリントに。
  - 弾き終わると「苦手なところ」（まちがいの多かった音）を表示し、楽譜でも赤く示す。その区切りをすぐ区間練習できる。
  - 両手モードでは、次の音を押さえるか・撥を上下どちらへ振るかも案内する。
- **クイズ**: 「二の糸の#」の場所をさがす勘所クイズ、光った場所の番号を答える番号あて、
  音を聴いて同じ高さを探す耳コピクイズ（ヒントあり）。それぞれ3段階のむずかしさ。
- **三味線のきほん**: 各部の名前、文化譜の読み方、調子（本調子・二上り・三下り）、本数、奏法の説明。
- 表示の切り替え: 文化譜の番号 / ドレミ / 音名、番号をかくす、勘所の範囲（0〜10 / 0〜20）、横向き・縦向き
- 奏法: 撥・スクイ・ハジキ・打ち指・スリ、サワリのオン・オフ

- **両手モード**: 左手で棹を押さえ、右手で胴の撥ゾーンを打つ本格的な弾き方（下へ＝叩き、上へ＝掬い、速さで強弱）。
- **MIDI 入力**: USB の MIDI キーボードや電子パッドで演奏（強さで音量と撥の音が変わる。Chrome・Edge）。
- **メトロノーム**: 二拍子・三拍子・四拍子、刻み（まっすぐ／8分／ハネ）、タップでテンポ。
- **チューナー**: 基準音（三味線の音のくり返し／持続音）と、マイクで本物の三味線の高さを測るモード。
- **キー表示**: パソコンのキーボードで弾くとき、どのキーがどの勘所かを棹に表示（タッチ画面のない Chromebook 向け）。
- **聴きくらべ**: 説明画面で、本調子・二上り・三下りの開放弦や、文化譜の各番号の音をその場で聴ける。
- **録音**: 弾いた音を録音して、その場で聴きなおしたり、ファイルとして保存したりできます。
- スマホ・タブレットではホーム画面に追加して、アプリのように使えます。
- 一度開けば、ネットがつながらなくても使えます（学校の Wi-Fi が不安定なときも安心）。

音はすべてその場で計算して作っています（録音した音源は使っていません）。
糸ごとの音色、一の糸のサワリ（山に触れて「ビーン」とうなる仕組み）、共鳴弦、
叩き・掬い・ハジキ・打ち指の違い、撥が皮を叩く音まで再現しています。

全部の勘所の音を画面を開いた直後から別スレッド（Web Worker）で作り置きし、まだできていない音は
近い高さの音を再生速度で合わせて即座に鳴らすので、遅いパソコンでもタップしてすぐ（数ミリ秒）に音が出ます。

## 授業で使うとき（例）

| 時間 | 内容 | 使う機能 |
|---|---|---|
| 1 | 各部の名前・3本の糸・開放弦 | 三味線のきほん／自由に弾く／曲「はじめの一歩」 |
| 2 | 文化譜の読み方と音階 | 曲「音階れんしゅう」／勘所クイズ・番号あて |
| 3 | 入門曲を弾く・リズム | かえるの合唱・メリーさんのひつじ・チューリップ／テンポ練習 |
| 4 | 日本の音階と調子のちがい | さくらさくら（スクイ）／二上り・三下りの音階／耳コピクイズ |

- 曲の練習の「🖨 印刷」で、その曲の文化譜を配布プリントにできます。
- 「録音」で演奏をファイルに保存できるので、提出にも使えます。
- 学習の記録（✓・★・クイズの最高記録）は、各端末のブラウザに保存されます（最初から通して弾けたときだけ記録）。
  共用端末では、説明画面の「授業で使うとき」にある「学習の記録を消す」でリセットできます。
- アクセシビリティの自動チェック（axe）で、全画面とも問題 0 件です。
- 実物の三味線を使う授業では「🎚 チューナー」で調弦を手伝えます。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000 で確認
npm run build   # dist/ に公開用ファイルができる
npm test        # 文化譜の番号や練習曲のデータが正しいか自動チェック
npm run lint    # 型チェック
```

## 公開ページ（GitHub Pages）

https://nakatadaiki1012-design.github.io/shamisen-simulator/

`main` に変更が入るたびに、GitHub Actions がアプリをビルドして自動で公開します
（`.github/workflows/deploy-pages.yml`）。
リポジトリの Settings → Pages の「Source」は **GitHub Actions** にしてください
（「Deploy from a branch」だとビルド前のファイルが公開され、画面が真っ白になります）。

## 公開（Cloudflare Workers・別の方法）

箏シミュレーターと同じく Cloudflare で公開できます。
Cloudflare のダッシュボードで「Workers & Pages → 作成 → GitHub リポジトリをインポート」からこのリポジトリを選び、

- ビルドコマンド: `npm run build`
- デプロイコマンド: `npx wrangler deploy`

を指定してください（設定は `wrangler.jsonc` に入っています）。
